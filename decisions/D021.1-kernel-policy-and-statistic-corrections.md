# D021.1 Amendment: kernel-confounding policy; corrected Hopkins, gap reference and Hennig failure handling

**Date**: 2026-10-05
**Stage**: discover (stage 6)
**Status**: Active (amends D021; D021's algorithms, k ranges, thresholds and bands are unchanged)
**Module**: `src/predict/discover/validity.py`, `src/predict/discover/clusterability.py`, `src/predict/discover/cluster_discovery.py`, `scripts/07_discover.py`

## Decision

1. **Kernel policy.** D021 makes a cluster x kernel chi-square failure (p < 0.05) a hard stop. Amended: for each algorithm at the forced k, the chi-square is computed as before. If it fails, the prespecified scanner-bias assessment is the likelihood-ratio test of kernel ~ cluster + log1p(Agatston) against kernel ~ log1p(Agatston) on the two main kernels (`kernel_association_given_burden`, the same code the earlier diagnosis used).
   - p_cluster_given_burden >= 0.05: status `explained_by_burden`. The association runs through burden, which differs between the two scanner populations. Stage 6 publishes, records the status per algorithm in `validity_checks.csv` and `COMPLETE_stage6.json`, and every downstream report must state it.
   - p_cluster_given_burden < 0.05: status `confounded`. The cluster carries kernel information beyond burden. Stage 6 exits 1 and publishes nothing (D021's hard stop, kept for this case).
   - A single-kernel cohort records `not_applicable_single_kernel`.
2. **Hopkins.** A query sampled from the data uses its second-nearest neighbour (skipping itself); a generated uniform query uses its nearest neighbour (it has no self-match). The 0.55 / 0.65 bands are unchanged.
3. **Gap statistic reference.** The uniform reference box is built in the input's own principal axes (SVD of the centred input, all dimensions kept, mapped back to input coordinates), as Tibshirani's PCA-uniform null specifies. This matters for burden-residualised PC scores, whose columns are correlated after the regression.
4. **Hennig bootstrap.** A failed refit raises; it is not scored as Jaccard 0. No class of fitting failure is defined as permissible.

## Rationale

All four are corrections of the stage 6 implementation.

- **Kernel.** The code only warned, contrary to D021's text. A documented, prespecified scanner-bias assessment is used rather than an unconditional stop. Disclosure: this rule is written after an earlier diagnosis (`scripts/diagnose_kernel_chi2.py`) had shown, under D033, a k-means forced-k3 chi-square of p 0.048 and a burden-adjusted p of 0.195 on nearly the same cohort. The test is therefore not blind to that dataset. It is the test that diagnosis already used, not one chosen afterwards, and the threshold is D021's own 0.05. A kernel association that survives burden adjustment still stops the stage.
- **Hopkins.** The uniform queries also skipped their nearest neighbour. Over 100 synthetic 1-D uniform datasets the statistic averaged 0.667 instead of about 0.5; the bias shrinks with dimension. A cluster probe with independent data and Hopkins seeds (2026-10-05) gave: old 0.659 in 1-D and 0.550 in 5-D (the ambiguous band's lower edge); corrected 0.500 and 0.501. With the data and Hopkins seeds equal, the uniform queries replay the data's own random stream and land on data points. The old rule skipped that coincident point and scored 0.501 in 5-D, which is very likely how the 2nd-neighbour rule was originally chosen (the old module doc described the corrected rule as giving "H near 0 on uniform random data"). The code's claim that this matched `pyclustertend` was wrong: that package uses the first neighbour for random queries. The bands are kept because they were defined for the standard statistic; the correction makes the computed value match that definition.
- **Gap.** The code used the per-column box of its input, which equals the PCA box only when the columns are principal axes (true for stage 5 PC scores, false after burden residualisation). In a synthetic regression example, the column box selected k = 6 and the same residuals rotated into their own principal axes selected k = 1, with identical pairwise distances.
- **Hennig.** The catch-all turned every failed fit into zero stability, so a software or numerical failure read as a biological finding. With every fit forced to fail, the function returned zero stability and no failure count.

## Consequence

Hopkins and gap values produced before D021.1 used the old definitions. For stage 5 PC scores the gap change only re-orients the reference box (their columns are already principal axes), so full-space results should shift only by sampling noise. The burden-residualised gap and every Hopkins value can change. The closed D036 / D036.1 detectability probes called `gap_statistic` with the old reference; their inputs are planted PC scores, close to principal axes, and they are not rerun.

## Reading of gap results (fixed 2026-10-05, before stage 6 ran under D021.1)

All gap-statistic results are descriptive outputs of the specified procedure. Selected k, including k = 1 or selection near the upper boundary, is not treated as evidence establishing or excluding discrete subtypes. Historical null-selection rates are reported as methodological context and are not transferred to uncalibrated feature spaces or the corrected implementation.

This applies to every feature space, algorithm and cohort. It extends D036.1's pre-registered reading (the gap arms fail the planted-group positive control up to delta 16) and D038 to all spaces.

Historical context, reported with its scenario stated: D036 / D036.1 delta = 0 runs, implementation before D021.1, 440-patient cohort before D039.1, simulation geometry N(0, real covariance) of the representative features, full feature space only, k 1..12, B = 100 reference draws, 120 datasets per algorithm. Selected k > 1: kmeans 10/120 (0.083), ward 7/120 (0.058), GMM 2/120 (0.017). The real matrix in the same runs: kmeans 11 to 12, ward 11 to 12, GMM 7 to 12 in 120/120. These are scenario-specific results, not calibrated false-alarm rates for the corrected implementation or for the burden-residualised and spatial-only spaces. Space-specific null probes are optional; they would be needed only if a gap result were later to support an inferential claim.

Why this was raised: in a thin-band scenario (300 points uniform along a line, so the data match the uniform reference), a 20-seed probe of the corrected implementation selected k = 1 in 8/20.
