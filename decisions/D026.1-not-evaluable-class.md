# D026.1 Features without a burden correlation are not evaluable, not "mixed"

**Date**: 2026-10-06
**Stage**: analyse
**Status**: Active (amends the implementation of D026; its four classes and thresholds are unchanged)
**Module**: `src/predict/analyse/monotonicity.py`, `src/predict/analyse/derived_features.py`, `src/predict/reduce/prepare_matrix.py`

## Decision

1. A feature whose Spearman rho against `agatston_total` cannot be computed (missing from the raw feature table, fewer than 5 values, or a constant feature or burden) gets the classification `not_evaluable`. It is never assigned one of the four D026 classes, and the summary table reports it in its own column.
2. Stage 7 re-derives `has_dense_calcium` at raw scale with the stage 5 function (`compute_has_dense_calcium`, D018), as it already does for `high_density_fraction` and `vessel_burden_gini`. Stage 5's binarisation calls the same function.

## Rationale

D026 defines four classes from rho and the feature's block; it does not cover a feature with no rho. The implementation labelled such features `mixed`, which reads as "intermediate burden association" when no association was measured. `has_dense_calcium` is a cross-cohort robust feature created in stage 5, absent from the raw `features.csv` that stage 7 reads, so it was classified `mixed` without being evaluated and had no stage 7 profile.

## Consequence

Stage 7 outputs change for `has_dense_calcium` (classification, profiles, consistency) and the D026 summary gains a `not_evaluable` column. In the run before this amendment the cross-cohort robust set was classified 17 burden-tracking, 12 mixed (including `has_dense_calcium`) and 4 structure-tracking.

## Verified by

- `tests/analyse/test_monotonicity.py`: NaN rho, a constant feature and a missing feature are `not_evaluable`; the summary has the `not_evaluable` column.
- `tests/analyse/test_derived_features.py`: the raw-scale `has_dense_calcium` equals stage 5's binarisation; the raw count is kept; no column without its source.
