# D028.1 Amendment: the low-burden sensitivity is computed in full and gets an explicit verdict

**Date**: 2026-10-05
**Stage**: analyse (stage 7)
**Status**: Active (amends D028; D028's subset, file layout and reuse of the full-cohort labels are unchanged)
**Module**: `src/predict/analyse/sensitivity.py`, `src/predict/analyse/paper_table.py`, `scripts/08_analyse.py`

## Decision

On the full cohort restricted to `low_burden_flag = False`, with the full cohort's spatial labels kept (no reclustering, as D028 specifies), stage 7 computes:

1. D024 burden orthogonality (`burden_orthogonality_robust_sensitivity.csv`).
2. The six D025 directional hypotheses (`directional_hypotheses_robust_sensitivity.csv`) and the D025 primary rule (at least 4 of 6 confirmed: direction match and FDR p < 0.05).
3. Cluster profiles and top-N signatures on the restricted patients (`cluster_profiles_robust_sensitivity.csv`, `signature_features_robust_sensitivity.csv`), which fill the signature column of the 5-row table.
4. A verdict (`robust_sensitivity_verdict.json`): for D024 and for the D025 primary rule, whether the restricted-cohort result is the same as the full-cohort result.

The D025 secondary rule (kernel strata) does not apply to one cohort. No Hennig value is reported for the subset: stage 6 Hennig values describe the full-cohort clusters.

## Rationale

D028 promised the orthogonality and directional files; the code produced only the descriptive table, and its five signature fields were blank because the full cohort's signatures carry the cohort label `full` while the table rows are labelled `robust`. D028 did not define how "preserved" is judged. The rule above uses the full analysis's own rules unchanged and only compares outcomes. It was fixed before stage 7 ran under it, and no subset outcome had been computed.
